# DejaVu Sans runtime assets

Unmodified DejaVu Sans 2.37 Regular and Bold, qualified in Commercial Workflow §33.
Upstream: https://dejavu-fonts.github.io/ . Exact font SHA-256 values are enforced
by the renderer and production-package smoke. Full embedding uses these local
assets, with no system-font fallback or resource fetch.

`font-license.txt` preserves the applicable Bitstream Vera copyright, trademark
and permission notice and the public-domain DejaVu additions. Its separate Debian
packaging stanza records acquisition provenance; no Debian packaging program is
included and the fonts are not described as GPL or OFL.
