# Journey map

**Status:** Active, first map ([#1277](https://github.com/Prisma-Prim/PRISMA-PRIM-Suite/issues/1277))

One row per acceptance journey, `apps/web/e2e/<journey>.acceptance.spec.ts`, named as `pnpm verify:journey --list` prints it. `scripts/journey-map.test.mjs` fails when a journey is missing from this table, when a row names a journey that no longer exists, or when a PRD link is broken. Add the row in the pull request that adds the spec.

**Widths.** Every journey is walked at both acceptance widths: desktop, 1440 × 900 (`operational-acceptance-desktop`), and narrow, 390 × 844 (`operational-acceptance-narrow`).

**Roles.** The fictional members come from the acceptance global setup; each journey's fixture grants them its Company role bundles. The member shown in the browser is listed first; the others act through the API in the spec, and an audit walks their screens by sending their test identity headers. The first audit that walks a journey corrects its row when the spec shows other roles.
