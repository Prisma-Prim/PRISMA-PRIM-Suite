## Parent

#500 - Client registration.

## What to build

A user registers a Client and finds it in the Client directory.

## Acceptance criteria

1. A user registers a Client and sees it in the directory at desktop and narrow widths.
2. The API rejects a duplicate legal identifier in the same Company.
   - The rejection names the existing Client only when the actor may see it.
3. The registration form shows the duplicate legal identifier error.

## Blocked by

None.
